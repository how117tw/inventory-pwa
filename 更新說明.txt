條碼盤點 V2.1 — 藍牙掃描槍數字面板版（2026/11/24）

適用：原有 how117tw.github.io/inventory-pwa/ 專業版 V2。
本檔案包尚未上傳至 GitHub，正式網站不會自動改變。

更新內容
1. 數量欄位提供網頁數字面板，不依賴 iPhone 系統鍵盤。
2. 條碼結尾 TAB 或 Enter 可跳至數量並開啟數字面板。
3. 提供 0～9、退格、清除、＋1、－1、確認送出與收合。
4. 數量為正整數，最多 10 碼。選取數字後可覆蓋輸入。
5. 儲存成功顯示條碼與數量，清空欄位並回到條碼欄。
6. 新增儲存期間重複送出防護；儲存失敗保留欄位供重試。
7. 更新 PWA 快取版本；保留原有 IndexedDB 資料庫名稱及同步、匯出流程。
本次僅處理數量輸入；庫別、Email 與手動條碼仍沿用原本輸入欄位。

GitHub 更新步驟
1. 先將手機待同步資料同步完成，並備份 GitHub 原始檔案。
2. 解壓縮更新包。
3. 開啟 how117tw/inventory-pwa 儲存庫中 GitHub Pages 使用的資料夾。
4. 以本包的 index.html、app.js、style.css、sw.js 覆蓋同名檔案。
   manifest.json、icon-192.png、icon-512.png 為原站下載的附件，既有檔案可保留。
   請將四個檔案放到原有檔案位置，不要多包一層資料夾。
5. 提交變更，等待 GitHub Pages 部署完成。
6. iPhone 連網開啟盤點系統，等候數秒讓新版背景下載，關閉所有該站 Safari 分頁及主畫面 PWA，再重新開啟。
7. 確認標題顯示「專業版 V2.1」。若仍為舊版，連網重新開啟、等待、關閉再開一次。
   請勿清除 Safari 網站資料或重設本機資料，避免刪除尚未同步的盤點紀錄。

iPhone 驗收
1. 保持 XD-3003W 藍牙連線，確認日期、庫別正確，點條碼欄。
2. 掃描商品（掃描槍結尾設定 TAB 或 Enter），確認數字面板出現。
   若掃描槍未設定結尾鍵，可自行點數量欄或「開啟數字面板」。
3. 點 1、2，確認數量為 12；測試退格、清除、＋1、－1。
4. 點「確認送出」，確認本機清單與數量正確、游標回到條碼欄。
5. 連續測試數筆，再測試離線新增及重新開啟仍保留資料，恢復上網後同步。
6. 使用測試日期／庫別進行測試，避免將測試紀錄混入正式盤點。

驗證範圍
JavaScript 語法檢查及 DOM 模擬邏輯測試通過：TAB/Enter、數字編輯與覆蓋、正整數及 10 碼限制、條碼前導零、重複送出防護、成功後游標返回、儲存失敗保留輸入。
目前環境未能啟動瀏覽器，未完成實際瀏覽器、離線快取、Google 同步及 iPhone／掃描槍硬體測試，以上需依驗收步驟確認。
